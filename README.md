# SCOOP — учебный сайт кафе-мороженого

Пять страниц: главная, сезон (вариант главной с другим первым экраном), меню, история бренда и визит. Дизайн основан на логотипе SCOOP №14.

## Запуск
Откройте папку в терминале и выполните `python3 -m http.server 8080`, затем откройте http://localhost:8080. Для работы модулей 3D нужен HTTP-сервер, а не file://.

## Возможности
- Локальная Three.js 0.170.0: интерактивный рожок, вращение мышью и стрелками, смена цвета, пауза; поддержка reduced motion и fallback при отсутствии WebGL.
- Два связанных слайда главной, переходы по навигации и кнопкам.
- Фильтры меню, случайный выбор вкуса внутри активного фильтра, раскрытие составов, FAQ.
- План визита сохраняется в localStorage и восстанавливается при повторном открытии.
- Адаптивная вёрстка, клавиатурная навигация, локальные шрифты Ubuntu.
- GitHub Pages: main, / (root); серверная часть и сборка не нужны.

## Соответствие заданию
Пять связанных страниц, второй вариант главной, центральный SVG-логотип, Ubuntu Bold 25 px в навигации desktop, две одинаковые кнопки радиусом 20 px, стрелки слайдера и вниз, полноширинная полоса, секции с изображениями. Для мобильных экранов размеры адаптируются. Настройки компонентов, сетки и прототипа Figma относятся к отдельному макету.
